# Tanvir — Personal Portfolio

A responsive futuristic dark-purple portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension (if you do not already have it).
3. Right-click `index.html` and choose **Open with Live Server**.

## Add your profile photo
Copy your chosen photo into `assets/` and rename it to `profile.jpg`.
The page currently shows a designed placeholder until that file exists.
